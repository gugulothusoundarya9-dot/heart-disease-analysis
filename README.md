# Heart Disease Analysis Dashboard

## Project Overview

This project is an interactive Heart Disease Analysis Dashboard developed using Microsoft Power BI. The dashboard analyzes patient health data and presents meaningful insights through interactive visualizations and KPIs.

## Tools & Technologies

- Power BI
- DAX
- Data Cleaning
- Data Visualization
- Excel / CSV

## Key Analysis

- Total number of patients
- Heart disease percentage
- Gender-wise analysis
- Age-wise analysis
- Health indicators
- Patient outcome analysis
- Interactive filtering and slicers

## Dashboard Features

- Interactive KPI cards
- Charts and visualizations
- Gender slicer
- Age-based analysis
- Interactive filters
- Data-driven insights

## Project Files

- `heart disease.pbix` – Power BI dashboard file
- `README.md` – Project documentation

## Objective

The main objective of this project is to analyze heart disease-related data and create an interactive dashboard that makes important health patterns and insights easier to understand.
